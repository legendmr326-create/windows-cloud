# Windows-Look Cloud Desktop (free, GitHub Codespaces)

1. Click Code -> Codespaces -> Create codespace on main
2. Wait 2 to 3 minutes for setup
3. Browser tab opens on port 6080 (noVNC)
4. Click Connect, password: vscode

Full Linux desktop (XFCE) with Firefox, in your browser, free.

## Mobile (Chrome/Android)
- noVNC has a keyboard icon (left side) to toggle typing on the phone
- Mouse mode: click/tap works; drag with the toolbar's drag button
- Use your browser's fullscreen option for fullscreen
